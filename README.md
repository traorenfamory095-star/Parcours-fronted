# parcours-frontend

Dépôt d'entraînement de N'Famory Traoré pour le parcours de préparation de l'équipe Frontend d'UGANC GUIDE (16 novembre 2026 au 3 janvier 2027).

Objectif : savoir construire seul une page de l'application web UGANC GUIDE avant le début du développement (11 janvier 2027).

## Structure

Un dossier par étape du parcours.

| Dossier | Étape | Statut |
|---|---|---|
| `01-html-css/` | HTML et CSS : fiche d'un lieu | En cours |
| `02-javascript/` | JavaScript : liste de lieux filtrable | À faire |
| `03-typescript/` | TypeScript : interface `Lieu` | À faire |
| `04-react/` | React : BarreRecherche, CarteLieu, ListeLieux | À faire |
| `05-nextjs/` | Next.js : pages /lieux et /lieux/[id] | À faire |
| `06-tailwind/` | Tailwind CSS aux couleurs de la charte | À faire |
| `07-leaflet/` | Carte Leaflet : page /carte | À faire |
| `08-api-rest/` | Appel à l'API UGANC GUIDE | À faire |
| `projet-final/` | Mini guide de campus | À faire |

## Lancer un exercice

Pour l'étape 1, il n'y a rien à installer : ouvrir `01-html-css/index.html` dans un navigateur.

Les étapes suivantes ajouteront leurs propres instructions dans le dossier concerné.
